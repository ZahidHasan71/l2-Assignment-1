# Advanced Problem Solving with TypeScript & OOP

This repository contains the solutions for the **B7A1 Assignment**, focusing on advanced TypeScript concepts, Object-Oriented Programming (OOP), and technical blog writing.

## Project Overview
The goal of this assignment is to demonstrate proficiency in:
- TypeScript Data Typing and Interfaces
- Functional Programming (Filtering, Mapping, Reversing)
- Generics and Type Constraints
- Type Guarding and Type Narrowing
- Object-Oriented Programming (Classes, Inheritance, and Encapsulation)
